# 顏色排序遊戲

這是一個簡單的色彩排序測驗。請觀察每排色塊的顏色，將中間的色塊重新排列，讓顏色由左至右形成平滑的漸層。

## 遊戲方式

1. 選擇難度：簡單、中等或困難。
2. 每排最左側與最右側的色塊是固定端點，不能移動。
3. 拖曳中間的色塊，依照色彩變化順序排列。
4. 完成四排後，按下「完成測驗」查看結果。

遊戲不計時，可以慢慢觀察顏色再進行排序。

## 難度

- **簡單**：每排 4 個可移動色塊
- **中等**：每排 8 個可移動色塊
- **困難**：每排 16 個可移動色塊
- **專家**：每排 16 個可移動色塊，色差最細微

難度越高，色塊越多、相鄰顏色也越接近。

## 分數

結果會同時顯示排序分數與原始誤差。

- 排序分數為 0～100 分，分數越高越好
- 100 分代表完美排序
- 原始誤差是每個色塊位置偏移的加總，數值越低越好，0 代表完全正確

結果頁也會顯示「色相誤差分布圖」，協助查看哪些色相區域較容易排錯。

## 重新開始

按下「再玩一次」即可重新產生一局新的測驗。
